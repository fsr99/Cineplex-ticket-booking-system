## Object Oriented programming 1(JAVA), Fall 2022

Project Description: This project is a Java based desktop cinema ticket booking system. It uses Swing to build a user friendly graphical interface with screens for the homepage, user registration, login, movie selection, showtime browsing, ticket pricing, seat selection, and payment processing. The application stores user information in local text files rather than a database, allowing users to create accounts, sign in, and complete a ticket booking flow. Overall, the project demonstrates core Java concepts such as GUI development, object oriented design, event handling, file I/O, and basic workflow management in a real world booking scenario.
